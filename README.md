# Study Assistant (Flam Frontend Internship Assignment)

Paste notes or a topic, get AI-generated flashcards, flip through them, mark each
one "Got it" or "Missed it", then re-test only the missed cards.

## Setup
1. Install Node 18+.
2. Get a free Gemini key at https://aistudio.google.com/apikey
3. Copy `.env.example` to `.env` and paste your key.
4. `npm install && npm start`
5. Open the URL Vite prints (usually http://localhost:5173).
